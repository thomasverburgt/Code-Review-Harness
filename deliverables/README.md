# Controlled Deliverables

This directory contains human-readable controlled outputs produced from repository source or evidence. Current files are agent prompt-design Word documents created during framework development.

Every future deliverable should have a neighboring manifest or index entry identifying its source, generator, version, hash, lifecycle state, and required human distribution authority. Temporary DOCX rendering work belongs under the ignored `_docx_work` directory; reusable builders belong in tracked source.
