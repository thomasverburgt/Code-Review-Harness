# Controlled Deliverables

This directory contains human-readable controlled outputs produced from repository source or evidence. Current files are agent prompt-design Word documents created during framework development.

The tracked [`release-manifest.json`](release-manifest.json) identifies the source builder, hash, size, and lifecycle state of each document. Builders are maintained under [`document_builders`](../document_builders/README.md).

Temporary DOCX rendering work belongs under the ignored `_docx_work` directory. Generation does not authorize leadership review or distribution; those transitions remain separate human-controlled records.
