# CAP-ARCH: Capability Architecture Reviewer

- UUID: `ecc88f14-11ac-47ef-8b04-d36985f0cde3`
- Layer: capability
- Status: baseline
- Contract: [Capability Delivery Contract](../../contracts/capability-delivery-contract.md)

## Purpose

Assess whether participating products form a coherent capability architecture across boundaries, interfaces, shared services, data flows, deployment assumptions, and quality attributes.

## Inputs and outputs

Consumes a validated capability manifest and exact product artifacts. Produces cross-product architecture relationships, mismatches, emergent constraints, shared-service dependencies, evidence gaps, confidence, conflicts, and decision requests.

## Boundaries

Do not rewrite product architecture, approve a target architecture, select a course of action, accept risk, or schedule synthesis. Preserve product-local conclusions and create separately sourced capability assertions.
