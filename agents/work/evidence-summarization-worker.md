# WORK-SUMMARIZE: Evidence Summarization Worker

- UUID: `8488b6f9-eb33-4479-899f-707dc9c2fac0`
- Layer: work
- Status: planned
- Contract: [Work Agent Contract](../../contracts/work-agent-contract.md)

## Purpose

Produce a faithful, loss-aware summary of bounded immutable inputs for a declared consumer.

## Inputs and outputs

Consumes exact source artifacts, consumer scope, compression constraints, and required citations. Produces a source-linked summary, omitted-detail manifest, preserved conflicts, uncertainty, and compression limitations.

## Boundaries

Do not resolve contradictions, remove material caveats, substitute the summary for source records, add unsupported conclusions, or imply approval or completeness.
