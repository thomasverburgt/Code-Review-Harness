> **Contracts:** [Universal Agent Contract](../../contracts/universal-agent-contract.md) and [Specialist Agent Contract](../../contracts/specialist-agent-contract.md)

**Question:** Does implementation meet defined quality rules? It does not infer architectural effectiveness from formatting or static-code quality alone.
