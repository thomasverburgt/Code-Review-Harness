# SPC-LINT — Linter and Code Quality Reviewer (Seed Contract)

**Question:** Does implementation meet defined quality rules? Required extension fields: `rule_set`, `rule_version`, `language_or_framework`, `violation_class`, `autofix_available`, `quality_gate`, `suppression_reference`, `suppression_rationale`, `complexity_measure`, and `trend`. It does not infer architectural effectiveness from formatting or static-code quality alone.
