# SPC-COMMS — Workload Communication Security Reviewer

**Question:** Are container-to-container and service-to-service boundaries protected against unauthorized access and lateral movement?

## Domain extension

Record `communication_topology`, `source_workload`, `destination_workload`, `protocol`, `sync_or_async`, `identity_mechanism`, `authentication`, `authorization`, `mtls_state`, `network_enforcement`, `data_classification`, `lateral_movement_path`, `failure_mode`, and `blast_radius`. A topology artifact is mandatory.

## Measures

Authenticated path coverage; authorized-path coverage; encrypted-path coverage; unbounded lateral-path count; and critical communication-path review coverage.
