# SPC-IO — I/O and Resource Interaction Reviewer (Seed Contract)

**Question:** Are storage and external I/O interactions safe, efficient, and resilient? Required extension fields: `resource_type`, `interaction_pattern`, `consistency_requirement`, `latency_or_throughput_expectation`, `failure_handling`, `retry_or_idempotency_behavior`, `backpressure_control`, `data_integrity_control`, `external_dependency`, and `resource_ownership`.
