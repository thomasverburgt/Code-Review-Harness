# Specialist Agent Specifications

This directory contains specialist role specifications and the [Specialist Agent Framework](specialist-agent-framework.md). The framework defines shared layer behavior; individual role files define the bounded scope, evidence expectations, exclusions, and outputs of registered specialists.

The canonical identity and lifecycle state of every role is maintained in [`../agent-identities.json`](../agent-identities.json). Sprint 5 will replace remaining shared-placeholder specifications with one specification per registered designation and generate repeated role tables from that registry.
