# CAPA Contract

Every finding requires a CAPA chain: root cause, corrective action for the present instance, preventive action against recurrence, accountable owner role, target horizon, implementation level, and validation method. CAPA is strictly for deficiencies; it must not be used to record a good practice.

Root-cause types: `design_flaw`, `implementation_defect`, `configuration_error`, `process_or_governance_gap`, `dependency_or_supplier_issue`, `insufficient_observability`, `external_constraint`, and `unknown`.
