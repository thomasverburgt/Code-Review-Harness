# Contract Catalog

| Contract class | Purpose | Producer | Primary consumers |
|---|---|---|---|
| Base agent envelope | Common provenance and review semantics | Every agent | Every parent/synthesis agent |
| Evidence | Immutable observable source | Collectors and every reviewer | All agents |
| Finding/CAPA | Deficiency, RCA, remediation, validation | Every reviewer | Product/capability risk and governance |
| Pattern/Insight | Good practice and neutral learning | Every reviewer | Architecture, maturity, learning agents |
| Specialist review | Domain assessment at product scope | Specialist agents | Product synthesis |
| Product synthesis | Integrated product engineering state | Product lead agents | Capability delivery layer |
| Capability assessment | Cross-product mission and readiness state | Capability agents | Enterprise synthesis |
| Enterprise decision brief | Strategic options and risk posture | Enterprise agents | Human governance board |

Contract extensions are additive. A breaking semantic change requires a major version and an ADR.
