# Rubrics

ADR-0039 Increment 1 adds comparison-only candidate rubrics for `SPEC-DEPS`, `SPEC-SBOM`, and `SPEC-LINT`. Each rubric evaluates its distinct authoritative question, exact evidence and focus bindings, honest missingness, locator quality, and authority limits; none grants admission or scheduling.

ADR-0039 Increment 2 adds comparison-only rubrics for `SPEC-CONTAINER`, `SPEC-CICD`, and `SPEC-IAC`. They enforce source/artifact/runtime separation, configured/executed/effective pipeline separation, desired/planned/applied/observed infrastructure separation, and human-only authority.

Rubrics define versioned evaluation criteria used by controlled agent executions. A rubric change is a candidate behavior change and must be calibrated and reviewed before promotion.
