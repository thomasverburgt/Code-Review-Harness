# Current Status Projections

This directory contains rebuildable views of the latest authoritative repository records. It is the navigation authority for current operational state, but it does not replace the ADRs, evidence packets, human responses, verifications, or ledger objects from which the views are derived.

- [`current-state.json`](current-state.json) is the machine-readable projection.
- [`current-state.md`](current-state.md) is the human-readable summary.

A projection correction does not rewrite historical evidence. Each entry cites the record that supplies its state and identifies remaining authority or evidence gates.
