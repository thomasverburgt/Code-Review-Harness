# Volume VII — GitLab CI/CD Integration

## Purpose

Describe how GitLab pipelines invoke the harness, collect and retain evidence, integrate merge-request and release gates, and connect to Platform Factory and ServiceNow controls.

## Baseline status

Structure established. The CI/CD specialist contract in Volume III provides relevant input semantics; this volume will define the integration architecture and pipeline examples.

## Planned contents

- Pipeline stages, runner roles, and artifact contracts
- Merge-request, branch, and release controls
- Security scan and evidence ingestion
- Credentials, retries, and failure behavior
- ServiceNow and deployment-promotion integration
