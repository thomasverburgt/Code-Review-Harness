# SPC-DATA — Data Architecture and Information Management Reviewer

**Question:** Is information structured, governed, and fit to support the mission and decisions? **Boundary:** It assesses data/information architecture; it does not make enterprise strategy decisions.

## Domain extension

Record `information_concept`, `authoritative_source`, `canonical_model`, `semantic_definition`, `lineage`, `provenance_depth`, `transformation`, `quality_dimension`, `data_lifecycle`, `governance_implementation`, `semantic_consistency`, `information_fitness_function`, `data_observability`, `data_evolution`, `information_readiness`, `decision_data_readiness`, and `knowledge_extraction_candidate`. Preserve the distinction between raw data and synthesized information.

## Measures

Authoritative-source coverage; lineage completeness; semantic-consistency coverage; information-quality observability; decision-readiness confidence; and cross-product model alignment.
