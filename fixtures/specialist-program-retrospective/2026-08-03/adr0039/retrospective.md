# ADR-0039 Specialist Program Retrospective

## Outcome

Candidate construction and GX-10 model calibration are complete for all 22 registered specialist agents. Every live role payload passed its strict schema, focus binding, admitted-evidence, deterministic projection, locator, and comparison-only lifecycle gates. The program consumed 53,369 input tokens and 8,641 output tokens.

This is machine preparation, not semantic completion. All 22 candidates are `blocked_on_evidence` because the consolidated human responses, qualified adjudications, and project-owner candidate dispositions do not yet exist. None is scheduled, eligible for product fan-in or reports, deployed, or authorized for A100 production.

## What worked

- A common envelope made every role interoperable with the same harness while strict role schemas kept domain output distinct.
- Focus profiles were hash-bound and compression-protected, preventing generic prompt reduction from erasing each specialist's authoritative questions.
- Evidence tiers stopped source and configuration from becoming claims of runtime effectiveness.
- Content-addressed child artifacts let `SPEC-RISK` and `SPEC-SECURITY` synthesize prior work without flattening source identifiers or inventing authority.
- Fail-closed pre-inference tests caught a GX-10 package omission before new inference began.
- The rotated key was streamed only for execution; the retained Increment 5-7 evidence contains zero exact-key or restricted-marker matches.

## What we learned

Schema validity is necessary but not sufficient. The harness can prove identity, provenance, evidence reference validity, lifecycle authority, and output shape; a qualified human must still judge whether a claim is semantically faithful and useful. Static evidence repeatedly showed why `configured_not_demonstrated` is an important state. The role prompts also need protected domain questions, evidence priorities, forbidden inferences, unknown-preservation rules, and authority boundaries—not merely a role title.

The largest unresolved measurement gap is human usefulness. We cannot yet report semantic fidelity, false-positive rate, reviewer agreement, or reproduction time. Latency instrumentation also needs a common per-role clock before comparing waves or projecting A100 performance.

## Corrective priorities

1. Run the consolidated human shadow-review dataset with general, restricted, and qualified tracks.
2. Adjudicate representative disagreements and record project-owner dispositions for every candidate.
3. Add uniform request, first-token, completion, retry, and projection timing to every live run.
4. Turn reviewer evidence requests and semantic defects into prompt, schema, rubric, or evidence-adapter revisions.
5. Propose any product fan-in, scheduling, deployment, or A100 production evaluation through a separate ADR with rollback.
